# ProverkaSklad

Мобильное веб-приложение AKFIX для проверки складских заказов, фотографирования палет и выгрузки результатов в Bitrix24 и Telegram.

## Документация

- [Архитектура](docs/ARCHITECTURE.md)
- [Развёртывание в Dokploy](docs/DEPLOYMENT.md)
- [Сценарий работы сотрудника](docs/WORKFLOW.md)

## Локальный запуск

Требуется Node.js 20 или новее.

1. Выполните `npm install`.
2. Настройте переменные окружения из `.env.example`.
3. Запустите `npm start`.
4. Откройте `http://localhost:8787`.

Без Bitrix-переменной приложение откроется с демонстрационными заказами.

## Формат сотрудников

`APP_USERS_JSON` — JSON-массив учётных записей. Каждая запись содержит `login`, `pin`, `name` и `warehouse`. В рабочей среде обязательно замените демонстрационные PIN-коды и задайте длинный случайный `SESSION_SECRET`.

## Текущее состояние

- список заказов из стадии Bitrix24 «Передан на сборку»;
- независимая проверка складов Мытищи и Балашиха;
- количество евро- и американских палет;
- три фотографии каждой палеты;
- подсказки для товаров Б и П;
- авторизация сотрудника с привязкой к складу;
- отдельная отправка результата каждого склада;
- загрузка фотографий в комментарий таймлайна Bitrix24;
- отправка фотоальбомов и подписи в Telegram.

Telegram принимает до 10 фотографий в одном альбоме. Если фотографий больше, приложение автоматически отправляет несколько последовательных альбомов.

Секреты нельзя добавлять в GitHub или клиентские файлы из `public/`.
