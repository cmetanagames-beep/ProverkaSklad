# ProverkaSklad

Мобильное приложение AKFIX для проверки складских заказов, фотографирования палет и последующей выгрузки результатов в Bitrix24 и Telegram.

## Локальный запуск

Требуется Node.js 20 или новее.

1. Создайте переменную окружения `BITRIX_WEBHOOK_BASE`.
2. Запустите `npm start`.
3. Откройте `http://localhost:8787`.

Без Bitrix-переменной приложение откроется с демонстрационными заказами.

## Развёртывание в Dokploy

- Build Type: `Dockerfile`.
- Container Port: `8787`.
- Domain Path: `/`.
- HTTPS: Let's Encrypt.
- Environment: `BITRIX_WEBHOOK_BASE`, позднее `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.

Секреты нельзя добавлять в GitHub или непосредственно в `index.html`.

## Текущее состояние

- список заказов из стадии Bitrix24 «Передан на сборку»;
- независимая проверка складов Мытищи и Балашиха;
- количество евро- и американских палет;
- три фотографии каждой палеты;
- подсказки для товаров Б и П;
- тестовый экран Telegram.

Фактическая отправка фотографий в Bitrix24 и Telegram будет подключена через серверный API на следующем этапе.
