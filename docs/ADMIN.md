# Администрирование

Панель находится по адресу `/admin.html` и доступна только пользователям с `role: "admin"`.

## Возможности

- поиск заказов в стадиях «Передан на сборку» и «Передан на проверку»;
- просмотр комментариев таймлайна заказа;
- удаление ошибочного комментария;
- очистка поля фотографий отдельно для склада Мытищи или Балашиха.
- создание сотрудников и изменение их имени, склада и PIN-кода;
- просмотр логина сотрудника (после создания логин фиксируется, поскольку к нему привязаны история и офлайн-очередь).

Каждая операция удаления требует подтверждения. Проверка роли выполняется сервером: обычный сотрудник не может вызвать административный API напрямую.

## Учётная запись

Администратор добавляется в `APP_USERS_JSON` без склада:

```json
{"login":"admin","pin":"CHANGE_ME","name":"Администратор","role":"admin"}
```

При первом запуске записи из `APP_USERS_JSON` сохраняются в `/app/data/users.json`. Дальше сотрудников нужно вести через вкладку «Сотрудники» в админ-панели. Volume `/app/data` сохраняет их после обновлений и перезапусков.
