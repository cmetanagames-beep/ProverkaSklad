# Офлайн-работа и обновления

- Список заказов сохраняется на телефоне после успешного получения из Bitrix24.
- Незавершённая выгрузка вместе с фотографиями записывается в IndexedDB браузера.
- Очередь не удаляется при выходе, истечении серверной сессии или обновлении приложения.
- После появления интернета приложение отправляет очередь автоматически. Проверки отправляются только под тем же логином, который их создал.
- Кнопка «Обновить заказы» запрашивает свежий список вручную.
- Service Worker хранит оболочку приложения для запуска без сети, но при наличии интернета всегда проверяет свежие файлы.
- Сервер выдаёт уникальную версию при каждом развёртывании. На безопасном экране приложение автоматически обновляется; во время фотографирования оно не перезагружается и не теряет выбранные файлы.

Для сохранения серверной истории, пользователей и независимой очереди выгрузки Bitrix24/Telegram в Dokploy должен быть подключён постоянный volume `/app/data`. Очередь продолжает работу после перезапуска контейнера и не требует повторной отправки фотографий с телефона.
