# Архитектура

## Каталоги

```text
public/
  index.html              Каркас мобильного интерфейса
  assets/styles.css       Стили AKFIX
  assets/app.js           Клиентский сценарий проверки
src/
  app.js                  HTTP-маршрутизация и статические файлы
  config.js               Чтение и проверка окружения
  auth/session-service.js Авторизация и подписанные сессии
  http/response.js        JSON-ответы и чтение запросов
  integrations/           Клиенты Bitrix24 и Telegram
  uploads/                Multipart-фото и завершение проверки
server.js                 Компоновка зависимостей и запуск сервера
```

## Границы безопасности

- токены Bitrix24 и Telegram доступны только серверу;
- клиент получает только имя и склад вошедшего сотрудника;
- сессия хранится в `HttpOnly`, `Secure`, `SameSite=Strict` cookie;
- API заказов и выгрузки требует действующую сессию;
- одна фотография ограничена 10 МБ, один запрос — 60 файлами.

## Интеграции

`BitrixClient` загружает фотографии методом `crm.item.update` в отдельное множественное поле склада: «Фото проверенного груза Балашиха» или «Фото проверенного груза Мытищи». Поле второго склада при этом не изменяется. `TelegramClient` отправляет фотографии альбомами по 10 элементов — это ограничение Bot API.
