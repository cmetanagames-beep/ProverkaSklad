# Памятка разработчику AKFIX

## Разовая настройка

```bash
pnpm install
pnpm run hooks
pnpm run check
```

## Работа над задачей

1. Создайте рабочую ветку от актуального `main`.
2. Не угадывайте поля Bitrix24, столбцы таблицы и Telegram-группы.
3. Меняйте только файлы текущей задачи.
4. Выполните `pnpm run check` и проверьте сценарий в браузере.
5. Просмотрите каждую строку `git diff`.
6. Создайте PR в `main` и дождитесь зелёного CI.

Секреты, PIN-коды, webhook, токены и реальные клиентские выгрузки в Git не добавляются.
